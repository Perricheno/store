# Перенос разработки на сервер

Состояние на 14 ноября 2026 (Asia/Almaty). Разработка продолжена на новом сервере в `/root/market/store`, ветка `feature/integrated-review`. Ноутбук с прежней средой недоступен; пользователь выбрал чистую dev-среду. Релиз v0.3.0 не выпущен, production не развернут.

## Ветки

- `dev`, тег `dev/v0.2.0`, коммит `86c0e2a` — ранее проверенная версия на ноутбуке; ее текущее состояние не проверено.
- `feature/integrated-review`, кандидат `5c446ef` — сводка, аналитика и маркетинг сотрудников; профиль, история, подборки, уведомления и помощь; денежный баланс; артикулы и EAN-13. Код кандидата проверен на новом сервере.

## Проверки на новом сервере

После чистой установки зависимостей через `npm ci` на Node.js 26.13.1 и npm 11.20.0 последовательно выполнены:

- `npm run typecheck` — успешно.
- `npm test` — 64 из 64: 45 core на PGlite, 7 worker, 6 покупательской логики, 5 корзины и 1 ограничения индексации; пропущенных нет.
- `npm run build` — успешная production-сборка Next.js 16.4.6 с webpack, без предупреждений сборки и прежних предупреждений standalone-трассировки.
- `npm run test:e2e` — все 52 HTTPS-сценария Chromium прошли за 1 минуту на отдельной тестовой PGlite-базе с mock-платежами. Установлен Chromium 1254 без изменения системных пакетов.

Прежний результат 51 из 52 относился к запуску до переноса: последний сценарий получал 429 из-за общего тестового IP. Сохраненное изменение IP проверено полным набором на сервере; ограничения входа приложения не менялись. Сценарии баланса, возврата сотрудником, аналитики и сохранения настроек прошли в составе полного набора.

Lighthouse 94/100 относится только к v0.2.0. Кандидат v0.3.0 отдельно не измерялся. E2E использует тестовый Next-сервер; самостоятельный standalone-артефакт кандидата пока не проверен. Production продвигается после проверок и пользовательского ревью.
