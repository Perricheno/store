# Релизы

Для каждого выпуска создайте JSON-манифест с массивами `Added`, `Improved`, `Fixed`, `Changed`, `Removed`. Каждый пункт — конкретное фактическое изменение на русском; пустой массив выводится как «Нет». Не объединяйте разные изменения в расплывчатую фразу и не заявляйте о непроведенных проверках. Манифесты хранятся в Git. Пример: `dev-v0.1.0.json`.

После создания коммита, завершения необходимых проверок и проверки адреса окружения сформируйте заметки:

```sh
node scripts/release.mjs --env dev --version 0.1.0 --manifest docs/releases/dev-v0.1.0.json
node scripts/release.mjs --env dev --version 0.1.0 --manifest docs/releases/dev-v0.1.0.json --tag
```

Заметки содержат SHA выбранного коммита, а аннотированный тег создается локально. По умолчанию выбран HEAD; `--commit SHA` позволяет выбрать конкретный существующий коммит. Создание тега не отправляет его на сервер и не развертывает приложение. Изменения манифеста должны входить в выпускаемый коммит. Проверяйте результаты тестов и внешний доступ отдельно.

После успешной проверки dev и решения о выпуске production используйте исходный dev-тег и манифест, который уже входит в этот коммит. Если состав выпуска совпадает, подойдет тот же манифест. Явно подтвердите проверку параметром `--tested`:

```sh
node scripts/release.mjs --env prod --version 0.1.0 --manifest docs/releases/dev-v0.1.0.json --from-dev-tag dev/v0.1.0 --tested --tag
```

Production-тег указывает ровно на тот же коммит, что dev-тег. `--tested` фиксирует утверждение оператора, а не выполняет тесты; версия и состав манифеста должны быть проверены человеком. Не создавайте production-тег до готовности выпуска.

Для GitHub сначала настройте и проверьте подходящий remote и авторизацию, отправьте коммит и нужный тег, затем повторите команду без `--tag`, добавив `--publish`. Необходим установленный `gh`; выпуск создается по уже существующему удаленному тегу. Dev помечается как prerelease, production — как стабильный выпуск. Инструмент не отправляет теги, не сохраняет учетные данные и не публикует автоматически. Сам релиз GitHub не развертывает приложение.
