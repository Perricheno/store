# Состояние проекта

Этот обзор описывает реализованные возможности и необходимые дальнейшие подключения. Production пока не развернут; A/B-тестирование не проводилось. Наличие кода, конфигурации или тестового сценария не означает успешного прохождения проверки или работы с реальным поставщиком.

Проверено 13 ноября 2026: TypeScript, production-сборка, 25 проверок core, 3 проверки адаптера ApiPay, проверка ограничения индексации и все 27 HTTPS E2E. E2E охватывают мобильную навигацию, три языка, серверные данные корзины, избранное при первом посещении, тестовую оплату, письмо, смену пароля, историю заказа и действия сотрудника. На публичном dev проверены загрузка каталога и корзины, отсутствие ошибок браузера и успешные ответы API. Это не заменяет пользовательское ревью или проверку реальных платежей.

Dev работает с PostgreSQL, worker, тестовой почтой Mailpit, Nginx и Cloudflare Tunnel. Production-база подготовлена отдельно; production-приложение еще не выпущено. Индексация временных доменов выключена.

Резервирование dev проверено фактическим восстановлением дампа в отдельную временную PostgreSQL-базу: восстановлены 500 товаров, временная база удалена после проверки. Архив фотографий читается; каталог резервной копии имеет права 0700, файлы — 0600.

Команды проверок и порядок запуска приведены в [README](../README.md). `npm run typecheck` проверяет TypeScript веб-приложения и core; `npm test` запускает тесты core, worker и безопасности; `npm run build` собирает веб-приложение; `npm run test:e2e` запускает браузерные сценарии с отдельной тестовой базой и mock-платежами. Проверка core на PostgreSQL требует отдельной пустой тестовой базы; такой запуск также описан в конфигурации CI. Итог текущих запусков сборки, браузерных тестов и CI следует подтверждать их фактическими результатами.
